# 🪑 Funimate — Online Furniture Store

[Live Site 🌐](https://furniture-ten-psi.vercel.app/)

**Funimate** is a sleek and responsive online furniture store designed with **Next.js**, **SCSS**, and **RxJS**, offering a seamless and modern shopping experience. Users can explore curated furniture collections, view product details, and manage their carts with ease.

## 🚀 Tech Stack

- **Next.js** – Framework for building optimized, SSR-friendly React apps
- **React.js** – Component-based UI
- **SCSS** – Modular, scalable styling
- **RxJS** – Reactive programming for state and event streams
- **Axios / Fetch API** – API data fetching
- **Framer Motion** – Smooth animations and transitions
- **Vercel** – Hosting and CI/CD

## 🖥 Features

- 📱 Fully responsive design
- 🛋️ Furniture product listings with clean UI
- 🔍 Product filtering and categorization
- 🛒 Add-to-cart and cart preview functionality
- ⚡ Optimized image loading and transitions
- ♻️ State managed using observables (RxJS)
